# Saurabh Agrawal — Finance & Data PGDM 3D Portfolio

Production-ready static portfolio for GitHub Pages.

## Files
- `index.html` — page structure
- `styles.css` — responsive styling and 3D/glass effects
- `script.js` — particles, interactions, scroll reveal and WhatsApp hiring form
- `assets/profile.jpg` — profile photo
- `assets/profile-icon.png` — favicon / Apple touch icon

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files/folders from this directory, keeping the `assets/` folder.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. GitHub will provide a `https://USERNAME.github.io/REPOSITORY/` URL.
5. Optional: add a custom domain under **Settings → Pages → Custom domain**.

## WhatsApp

## Mobile
The page is designed for iOS Safari, iPadOS, Android Chrome and desktop browsers. Hover-only effects are not required on touch devices, and form inputs use 16px text on small screens to avoid Safari auto-zoom.
